Network Protocols & Web Concepts

Interactive study reference & CBSE Practice Quiz Guide

Web Browsing

HTTP

Hypertext Transfer Protocol: Used for browsing the internet and requesting web content from web servers.

Security

HTTPS

Hypertext Transfer Protocol Secure: Uses additional encryption to ensure secure communication and web browsing.

File Management

FTP

File Transfer Protocol: Used for uploading and downloading files over the internet.

Email

SMTP

Simple Mail Transfer Protocol: Used for sending emails across networks.

Email

POP3

Post Office Protocol (v3): Used for receiving emails from a mail server.

Direct Connection

PPP

Point-to-Point Protocol: Establishes a direct connection between two network devices.

Core Suite

TCP / IP

TCP: Provides reliable data transmission.
IP: Handles addressing and routing of packets.
Native/standard protocol suite of the Internet.

Remote Access

TELNET

Allows a user to log in to and operate a remote computer system securely or over a network.

Voice & Video

VoIP

Voice over Internet Protocol: Allows voice calls over the Internet. Used extensively in video conferencing to carry audio/voice traffic over IP networks.

Interactive URL Breakdown

A URL (Uniform Resource Locator) is the complete address used to locate a specific resource on the web.

https:// www.cbse.gov.in /cbsenew/cbse.html
Protocol: `https://` (Secure Web Protocol)
Domain Name: `cbse.gov.in` (Human-readable website name)
Path/File: `/cbsenew/cbse.html` (Specific web page location)
Web Architecture

WWW (World Wide Web)

A system of interconnected web pages and resources accessed via the Internet using web browsers.

Client Side

Web Browser

Client software used to access, retrieve, and display web pages.


Examples: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, Opera.

Server Side

Web Server

Software running on a computer that receives client requests and serves requested web pages back.


Examples: Apache, Nginx, Microsoft IIS.

Infrastructure

Web Hosting

A service that provides server storage space to store website files, making the website accessible worldwide on the Internet.

HTML vs XML

Markup languages serve different purposes in web development and data exchange.

Feature HTML (HyperText Markup Language) XML (eXtensible Markup Language)
Primary Purpose Used to create, structure, and design web pages. Used to store and exchange structured data.
Tags Uses predefined (built-in) tags (e.g., <p>, <h1>). Allows user-defined custom tags (e.g., <student>).
Focus Focuses on how data looks (presentation/design). Focuses on what data is (data transport & storage).
