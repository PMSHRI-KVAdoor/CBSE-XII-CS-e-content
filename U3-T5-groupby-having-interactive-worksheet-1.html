5. Query Builder

Q5. Write a query to display department-wise average salary.

SELECT Department, AVG(Salary)
FROM EMPLOYEE
GROUP BY Department;

Q6. Write a query to display departments having more than 2 employees.

SELECT Department, COUNT(*)
FROM EMPLOYEE
GROUP BY Department
HAVING COUNT(*) > 2;

6. Find the Error

SELECT Department, COUNT(*)
FROM EMPLOYEE
WHERE COUNT(*) > 2
GROUP BY Department;

What is wrong?

COUNT(*) is an aggregate expression. An aggregate condition on grouped results should be placed in HAVING, not WHERE.

7. CBSE-Style Challenge

Write a query to display total sales region-wise, keep only regions whose total exceeds ₹10,000, and show the result in descending order.

SELECT Region, SUM(Amount)
FROM SALES
GROUP BY Region
HAVING SUM(Amount) > 10000
ORDER BY SUM(Amount) DESC;
