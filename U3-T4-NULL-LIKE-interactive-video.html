Working table

00 The Student table

Every example below runs against this one table. Grade and Remarks are deliberately left blank for some students — that's where NULL comes in later.

Table name: Student  ·  Columns: RollNo, SName, Stream, Marks, Grade, City, Remarks  ·  a blank cell means the value is NULL, not the text "NULL".

Clause

01 The ORDER BY clause

ORDER BY arranges the rows of the result in ascending or descending order of one or more columns. By default, sorting is ascending (ASC); use DESC for descending. It is always the last clause in a SELECT statement.

SELECT column_list FROM table_name [WHERE condition] ORDER BY column1 [ASC|DESC], column2 [ASC|DESC], ...;
SQL> SELECT SName, Stream, Marks FROM Student ORDER BY Marks DESC;
Highest scorer first — the whole table, sorted by one numeric column.
SQL> SELECT SName, Stream, Marks FROM Student ORDER BY Stream, Marks DESC;
Multi-column sort: streams alphabetically, and within each stream, highest marks first.
Exam tip: "ORDER BY 2 DESC" is also valid — 2 refers to the position of the column in the SELECT list. Sorting on a column not shown in the output is allowed too.

Special value

02 Meaning of NULL, IS NULL, IS NOT NULL

NULL means a value that is unknown, unavailable, or not applicable — it is not zero, not blank text, and not equal to anything, including another NULL. That is why WHERE Grade = NULL never matches any row; SQL provides a dedicated test instead.

column_name IS NULL -- true only when the value is missing column_name IS NOT NULL -- true only when a value is present
SQL> SELECT SName, Grade FROM Student WHERE Grade IS NULL;
Students whose grade has not been entered yet.
SQL> SELECT SName, Remarks FROM Student WHERE Remarks IS NOT NULL;
Only students who actually have a remark on file.
Common board slip: writing WHERE Grade = NULL or WHERE Grade != NULL. Both return zero rows — NULL can only be tested with IS NULL / IS NOT NULL.

Pattern matching

03 The LIKE operator

LIKE searches for a pattern within a text column, using two wildcards:

% any sequence of zero or more characters _ exactly one character
SQL> SELECT SName FROM Student WHERE SName LIKE 'S%';
Names starting with "S".
SQL> SELECT SName FROM Student WHERE SName LIKE '%a';
Names ending in "a".
SQL> SELECT SName FROM Student WHERE SName LIKE '_a%';
Second letter is exactly "a" — one underscore, then anything.
Use NOT LIKE for the opposite match, e.g. WHERE City NOT LIKE 'D%' excludes every city beginning with "D".

Data manipulation

04 The UPDATE command

UPDATE changes the values of existing rows. Without a WHERE clause it changes every row in the table — almost always a mistake in an exam answer unless the question explicitly asks for it.

UPDATE table_name SET column1 = value1, column2 = value2, ... [WHERE condition];
SQL> UPDATE Student SET Grade = 'A' WHERE Marks >= 90;
Run this in the console below, then SELECT the table again — you'll see the change persist.
To clear a value rather than replace it, set it to NULL: UPDATE Student SET Remarks = NULL WHERE RollNo = 9;

Data manipulation

05 The DELETE command

DELETE removes entire rows from a table — never individual column values (use UPDATE ... SET col = NULL for that). Like UPDATE, leaving out WHERE removes every row, though the empty table itself still exists.

DELETE FROM table_name [WHERE condition];
SQL> DELETE FROM Student WHERE Marks < 40;
Removes any student who failed outright. Try it, then use Reset Table to bring the row back.
DELETE vs DROP: DELETE removes rows (structure stays); DROP removes the entire table (structure gone). Only DELETE is on this syllabus's DML list.

Summarising data

06 Aggregate functions

Aggregate functions collapse many rows into one summary value. All five ignore NULL values except COUNT(*).

MAX(column) -- largest value MIN(column) -- smallest value AVG(column) -- average of non-NULL values SUM(column) -- total of non-NULL values COUNT(column) -- number of non-NULL values in that column COUNT(*) -- number of rows, NULLs included
SQL> SELECT MAX(Marks), MIN(Marks), AVG(Marks), COUNT(*) FROM Student;
One row of summary statistics for the whole table.
SQL> SELECT Stream, COUNT(*), AVG(Marks) FROM Student GROUP BY Stream;
GROUP BY produces one summary row per distinct value of Stream.
SQL> SELECT COUNT(Grade), COUNT(*) FROM Student;
COUNT(Grade) skips the NULL grades; COUNT(*) counts every row regardless.

08 Practice questions

A · Short answer (1–2 marks)

What is the default sorting order of ORDER BY? How do you reverse it? 2
The default is ascending (ASC). Append DESC after the column name to sort in descending order, e.g. SELECT * FROM Student ORDER BY Marks DESC;
Why does Grade = NULL fail to select any row, even where Grade is genuinely blank? 2
NULL represents an unknown value, so it cannot be compared using = — an unknown value is never "equal to" anything, not even another NULL. SQL requires the special predicates IS NULL and IS NOT NULL to test for missing values.
Differentiate between the DELETE and UPDATE commands. 2
UPDATE modifies the value(s) of existing column(s) in rows that match a condition — the row stays, only the data changes. DELETE removes entire rows that match a condition from the table; the columns of the table remain, but the row itself is gone.
What is the difference between COUNT(*) and COUNT(column_name)? 2
COUNT(*) counts every row in the result, including rows where the column is NULL. COUNT(column_name) counts only the rows where that specific column has a non-NULL value.
What will SELECT SName FROM Student WHERE SName LIKE '__a%'; return? 2
Names whose third character is "a": two underscores match any two characters, then a literal "a", then % matches anything after.

B · Query writing, using the Student table above (2–4 marks)

Write a query to display the name and marks of students in descending order of marks. 2
SELECT SName, Marks FROM Student ORDER BY Marks DESC;
Write a query to display students who have not yet been given a grade. 2
SELECT SName FROM Student WHERE Grade IS NULL;
Write a query to display students from Mumbai or Pune whose name contains the letter "a". 3
SELECT SName, City FROM Student WHERE (City = 'Mumbai' OR City = 'Pune') AND SName LIKE '%a%';

(This console accepts one level of OR grouped with AND — try it above.)

Write a query to change the grade to 'B' for every student scoring between 60 and 80 marks (both inclusive). 3
UPDATE Student SET Grade = 'B' WHERE Marks >= 60 AND Marks <= 80;
Write a query to delete the record of the student with RollNo 7. 2
DELETE FROM Student WHERE RollNo = 7;
Write a query to display the highest and lowest marks scored, stream-wise. 3
SELECT Stream, MAX(Marks), MIN(Marks) FROM Student GROUP BY Stream;
Write a query to count how many students scored above 80 marks. 2
SELECT COUNT(*) FROM Student WHERE Marks > 80;

C · Predict the output

Predict the output: SELECT SName FROM Student WHERE Remarks IS NOT NULL ORDER BY SName; 2
Alphabetically-ordered names of only those students who have some entry in the Remarks column — students with a blank Remarks are excluded entirely. Run it in the console to check your prediction.
Predict the output: SELECT AVG(Marks) FROM Student WHERE Stream = 'Arts'; 2
A single value: the average Marks of only the rows where Stream is 'Arts'. Try it, then compare with the same query for 'Science' and 'Commerce'.
