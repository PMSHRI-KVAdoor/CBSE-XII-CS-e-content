1. 🧠 Quick Concept Check

SQL stands for Structured Query Language. It is used to create, manage and manipulate data in relational databases.

DDL – Data Definition Language: defines/changes database structures.

DML – Data Manipulation Language: works with the data stored in tables.

Examples: DDL – CREATE, ALTER, DROP | DML – INSERT, UPDATE, DELETE

4. 🔐 Constraints

NOT NULL: A column cannot contain a NULL value.

UNIQUE: Values in the column must be different.

PRIMARY KEY: Uniquely identifies each record; it cannot contain NULL values.

7. 📝 Short Answer

Model Answer: DDL is used to define or modify the structure of database objects, while DML is used to insert, update or delete data stored in tables.
