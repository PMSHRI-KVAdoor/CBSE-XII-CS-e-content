1. SHOW TABLES & DESCRIBE

The SHOW TABLES command lists all tables in the current database. The DESCRIBE or DESC command is used to view the field names, datatypes, and structure of a specific table.

SHOW TABLES;
DESCRIBE STUDENT; -- or DESC STUDENT;

2. CREATE TABLE & ALTER TABLE

Use CREATE TABLE to construct a brand new table. Use ALTER TABLE to modify the existing table structure, such as adding, modifying, or dropping columns, or altering the primary key.

CREATE TABLE STUDENT (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(30),
    Marks DECIMAL(5,2)
);

ALTER TABLE EMPLOYEE ADD Email VARCHAR(25);
ALTER TABLE EMPLOYEE MODIFY Name VARCHAR(50);
ALTER TABLE EMPLOYEE RENAME COLUMN Name TO ENAME;
ALTER TABLE EMPLOYEE DROP COLUMN Gender;

3. SELECT, DISTINCT & ALIASING

SELECT retrieves data. DISTINCT removes duplicate rows from output. The AS keyword provides temporary column aliases for cleaner output.

SELECT DISTINCT gender FROM EMPLOYEE;
SELECT Name AS Student_Name, Marks + 5 FROM STUDENT;

4. WHERE Clause, IN & BETWEEN Operators

The WHERE clause filters table rows based on conditions. The BETWEEN operator checks for values within an inclusive range. The IN operator checks if a value matches any element in a specific list.

SELECT * FROM EMPLOYEE WHERE salary BETWEEN 30000 AND 50000;
SELECT * FROM EMPLOYEE WHERE deptno IN (10, 20, 30);
SELECT * FROM EMPLOYEE WHERE gender = 'F' AND salary > 50000;
